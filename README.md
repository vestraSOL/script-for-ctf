# script-for-ctf
sql_injection,idor,path_traversal,command_injection
## Техники

Скрипт прогоняет по каждой цели четыре класса веб-атак и собирает флаги из ответов по регулярке:

1. **IDOR (Broken Access Control)** — перебор числовых `id` на `/note?id=`.
   Сервис отдаёт любую заметку по id без проверки владельца, поэтому
   перебором id вытягиваются чужие приватные заметки с флагами.

2. **SQL-инъекция (UNION-based)** — payload в `/search?q=`.
   Пользовательский ввод склеивается в SQL-запрос, через `UNION SELECT`
   из базы выгружаются произвольные таблицы (флаги, учётные данные).

3. **Path Traversal** — `../` в параметре `/file?name=`.
   Имя файла склеивается с путём без фильтрации, что позволяет выйти за
   пределы рабочей папки и прочитать произвольные файлы (исходники, БД).

4. **Command Injection** — shell-метасимволы в `/ping?host=`.
   Ввод попадает в shell-команду, через `;` выполняется произвольная
   команда на сервере (например, дамп базы данных с флагами).

Цели обрабатываются параллельно; флаги печатаются в stdout
(совместимо с exploit-фермами), статус — в stderr.
